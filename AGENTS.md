Next.js 16.3 (App Router) + React 19 + Tailwind CSS v4 + TypeScript site for **Detalles Maranatha**, a Colombian flower-arrangements and gift business. Stack: GSAP 3.15 + Lenis 1.3.26.

## Decisions already locked (do not re-litigate)

- **Next.js App Router, not a Vite SPA.** SSG + ISR for catalog/product pages, SSG for institutional pages. GSAP runs only in `"use client"` components; content (text, prices, names) renders on the server and must never depend on JS-only animation to exist in the DOM (SEO).
- **GSAP** core + ScrollTrigger + Flip + SplitType (open-source; not Club GreenSock premium plugins), Lenis smooth scroll, `gsap.matchMedia()` to disable parallax/pinning on mobile.
- **Tailwind v4 CSS-first config** (no `tailwind.config`): brand tokens are CSS variables in `app/globals.css`, mapped via `@theme inline` as `--color-mar-*` (palette) and `--color-mood-*` (section moods). Fonts: Fraunces (`--font-display`) + Inter (`--font-sans`) via `next/font`.
- **Dynamic per-session theme**: 4-6 curated themes applied via CSS variables, persisted in `sessionStorage` only (purely decorative/client-side).
- **Mobile-first** (>80% of traffic is mobile in Colombia): lightbox must support swipe, WhatsApp CTA in thumb zone, no heavy hero video on mobile.
- **SEO**: zone pages under `/domicilios/[ciudad]`; Phase 1 ships only Bogotá + zones with real delivery coverage. Dynamic sitemap (sitemap index), schema.org `LocalBusiness`/`Product`, `next/font` (never external `<link>` fonts).
- **Performance budget (mobile)**: LCP < 2.0s, INP < 150ms, CLS < 0.05, Lighthouse ≥ 90, home < 1.5 MB transferred.
